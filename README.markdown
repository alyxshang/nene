# NENE

![Nene CI](https://github.com/alyxshang/nene/actions/workflows/zig.yml/badge.svg)

***The interpreter for a statically-typed, functional, semi-esoteric programming language.***

## ABOUT

This repository contains the source code for the interpreter for a statically-typed, functional, semi-esoteric programming language. The name, Nene, comes from the Nahuatl word for "doll", "Nenetl".
This language was invented by me and the specification was also written by me.

## SPECIFICATION

A specification of the Nene programming language can be found [here](https://alyxshang.boo/specs/nene).
